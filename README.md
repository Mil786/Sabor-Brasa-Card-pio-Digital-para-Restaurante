# 🔥 Sabor Brasa — Cardápio Digital para Restaurante

Um projeto de **cardápio digital para restaurante**, desenvolvido como demonstração de uma solução web moderna, responsiva e intuitiva para apresentação de produtos e informações de um estabelecimento.

Este projeto faz parte do meu **portfólio de desenvolvimento web**, demonstrando habilidades em HTML, CSS e JavaScript.

## 🌐 Demonstração

🔗 **Acesse o site:**  https://mil786.github.io/Sabor-Brasa-Card-pio-Digital-para-Restaurante/

---

## 📱 Sobre o Projeto

O **Sabor Brasa** apresenta uma proposta visual de cardápio digital para um restaurante fictício, com foco em uma experiência simples, moderna e agradável para os clientes.

A interface foi desenvolvida pensando principalmente em dispositivos móveis, mas também possui adaptação para tablets e computadores.

A proposta simula uma solução que poderia ser utilizada por restaurantes para apresentar seus produtos de forma profissional através da internet.

## ⚠️ Aviso Importante

### Projeto Demonstrativo

**Sabor Brasa é uma marca fictícia criada exclusivamente para fins de demonstração, estudo e portfólio.**

Este projeto **não representa um restaurante real** e não possui vínculo, parceria, autorização ou associação com qualquer empresa, restaurante, marca ou estabelecimento existente.

Os nomes, produtos, preços, descrições, identidade visual, imagens e demais elementos apresentados neste projeto foram utilizados exclusivamente para fins demonstrativos.

Caso exista alguma empresa ou marca com nome semelhante, este projeto **não possui relação com ela e não pretende representar ou se passar por qualquer empresa existente**.

As imagens e informações utilizadas no projeto possuem finalidade exclusivamente ilustrativa.
